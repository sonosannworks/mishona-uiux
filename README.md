# L Message「予約管理」UI/UX改善提案

薗田信広_ミショナUIUX課題（株式会社ミショナ UI/UXデザイナー職 職種別課題）

- `index.html` … 表紙と一覧（各画面の見本 1280×800、改善のポイント、改善前の画面）
- `calendar.html` … 画面1 予約カレンダー（操作できるプロトタイプ）
- `add.html` … 画面2 予約追加（入力｜結果）＋ 画面3 登録前の確認ダイアログ（`add.html?demo=confirm` で直接開く）
- `today.html` … 画面5 今朝の確認（近未来の提案：AIのまとめと留守番電話からの予約の下書き。実現の段階をバッジで表示）
- `settings.html` … 画面4 予約設定（予約時・変更時・キャンセル時の要約カード、予約の入口）
- `css/common.css` … L Messageのデザインガイド（色・文字）に合わせた共通のスタイル
- `js/` … 架空の予約データ、画面の描画、プレゼン用ツールバー（提案メモ・注釈）
- `images/` … 改善前のスクリーンショット（before-screen1.png 〜 before-screen5.png）

プロトタイプで登録した予約は、ブラウザのタブを閉じるまで残ります。ツールバーの「最初から」で初期の状態に戻せます。
